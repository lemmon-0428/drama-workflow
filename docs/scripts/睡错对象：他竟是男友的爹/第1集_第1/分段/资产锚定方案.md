## 4. 每段 ref_set 策略

每段 `ref_set` 均按以下顺序写入 `资产绑定.json`：

1. `@[board:]` 草图板，构图/机位/硬切主引导。
2. `@[palette:]` 色卡，锁定调色。
3. `@[char:]` 角色，只有本段露脸或身体/反应是主体时锚。
4. `@[prop:]` 道具，只有道具对剧情理解重要时锚。
5. `@[scene:]` 场景，仅在环境本身是主体或空间关系必须锁定时锚。

本集所有段的图片参考数均小于 9 张：

| 段 | ref 数 | 场景锚定说明 |
|---|---:|---|
| SEG-1A | 7 | 需要建立夜晚客厅、侧桌手机与仪式空间 |
| SEG-1B | 4 | 紧镜等待，不锚场景，减少噪音 |
| SEG-1C | 5 | 人物/道具为主体，不锚场景 |
| SEG-1D | 3 | 纯省略段，只锚板、色卡、红色道具 |
| SEG-1E | 7 | 清晨客厅和窗台相框是身份揭示主体 |
| SEG-1F | 6 | 门框空间是撞破主体，锚门口场景 |

## 5. 两处用到锚定

生成草图板时：

- SEG-1A 引用 `@[prop:red_restraint_set]` 和 `@[prop:phone_damon_call]`，确保红色道具形状和 Damon 来电文字一致。
- SEG-1B / 1C 引用 `@[prop:red_restraint_set]`，确保等待和伊森入场里的红色道具一致。
- SEG-1E 引用 `@[prop:father_son_photo_frame]` 与 `@[prop:red_restraint_set]`，确保相框和后果证物一致；Panel 4 已重做为仅包含红色眼罩、金属手铐、红色球形绑带口衔、红色羽毛棒、衣物和奥利弗的手。
- SEG-1F 引用 `@[staging:ep1_1F]`，确保门口三人调度、机位侧和 180°轴一致。

拼 SD2 请求时：

- 下游读取 `资产绑定.json.assets` 解析 token 到路径。
- 下游按每段 `segments[].ref_set` 顺序上传图片并构造 `reference_images`。
- `@[board:]` 永远排第1，作为构图主引导；文本 prompt 使用 `段提示词.md` 对应段全文。

## 6. 安全与画面边界

本集原剧本含成人亲密与强烈控制情节。分段蓝图采用悬疑短剧表达：道具、反应、剪影、壁炉、黑屏和清晨后果证物，不把露骨动作画进草图板或 prose。下游视频请求也应保持这个边界。

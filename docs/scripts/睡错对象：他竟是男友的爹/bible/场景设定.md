# 睡错对象：他竟是男友的爹 · 场景设定

> 场景设计的人读正本；机器可消费规格见 `bible.json` 的 scene assets。

## The Ville 顶层公寓客厅  `ville_penthouse_living_room`

- 出现场次：第1集 1-1 / 1-2 / 1-3。
- 环境定位：现代极简主义顶层公寓客厅，巨大落地窗俯瞰城市夜景，昂贵但冷清。黑色石材、玻璃、低矮皮质沙发、金属边桌、壁炉构成主要视觉元素。
- 情绪功能：亲密游戏、身份错位、清晨反转都发生在这里。它不是温暖的家，而是一个漂亮、封闭、可被观看的权力空间。
- 视觉母题：落地窗负责“看 / 被看”，壁炉负责“欲望燃烧”，玻璃和相框负责“反射 / 身份揭示”。
- look 规划：
  - `night_dim`：夜晚低照度，城市灯海、壁炉火光、黑金空间、红色道具点缀。
  - `morning_cold`：清晨冷白阳光，沙发与相框被照亮，秘密被暴露。
- 来源依据：剧本头部主要场景说明、第一集 1-1 至 1-3。

## 贾斯帕卧室门口 / 套房走廊  `jasper_bedroom_doorway`

- 出现场次：第1集 1-3 末尾。
- 环境定位：顶层公寓内部卧室门口与短走廊，材质延续黑白极简、金属把手、浅色墙面或隐形门。门框是“撞破”的视觉框。
- 情绪功能：奥利弗试图逃回贾斯帕的卧室，门被拉开，贾斯帕推门而入，形成误以为“被男友撞破”的假一镜。
- look 规划：
  - `morning_reveal`：清晨冷白光，门框强构图，人物被困在同一条视线轴线上。
- 来源依据：第一集 1-3 末尾门口调度。

## 道具设计摘要

### 红色亲密道具组  `red_restraint_set`

- 内容：红色眼罩、红色口球、金属手铐、红色羽毛棒。
- 功能：开场关系仪式的视觉钩子，之后作为地上散落物提醒奥利弗昨夜失控。
- 设计：深红缎面 / 皮革 + 冷金属，奢华但危险；成图必须是静物道具，不带人体，不色情化。

### 父子合照相框  `father_son_photo_frame`

- 内容：窗台或边桌上的高级相框，画面中是伊森与贾斯帕父子合照；照片内人物必须沿用当前新版 Ethan / Jasper 角色参考表，锁定白人父子面孔、发型与年龄差。
- 功能：清晨揭示伊森真实身份的关键证物。
- 设计：黑色或银色金属相框，玻璃反射能映出奥利弗惊惶倒影；相框内父子照已按当前新版 Ethan / Jasper 角色参考表重做，不使用泛化父子照片。

### Damon 来电手机  `phone_damon_call`

- 内容：黑色智能手机，来电界面显示 Damon。
- 功能：打断贾斯帕与奥利弗，使贾斯帕离开，为身份错位打开缺口。
- 设计：冷白屏幕文字、黑色机身，作为夜色里刺眼的外部扰动。

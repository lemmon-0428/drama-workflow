# 步步生金（走路赚钱） · 剧集总览

【剧名】《步步生金》
【题材】青春 / 奇幻 / 逆袭 / 亲情

【故事梗概】
本剧本涵盖了原著前20章的全部核心剧情，将其梳理为一部节奏紧凑、高潮迭起的四幕剧。保留了原著"走路赚钱"、"学霸逆袭"、"系统升级"的爽点，同时丰富了人物之间的情感羁绊。

【拆分说明】
源文件 `原始剧本_步步生金.docx` 为 Markdown 格式大纲，全文挤在单个段落里、用 `### 【第N幕】` 标记分幕（python-docx 与拆分脚本无法按常规"第N集"切分），故人工拆分。
原结构为"四幕剧 + 片头钩子 + 片尾钩子"，共 13 个场景。按"四幕剧 = 4 集"切分：片头钩子并入第 1 集、片尾钩子并入第 4 集。时间码原文未标（大纲无显式时长）。

【分集目录】
- 第1集_绝望降临   片头钩子【魔鬼的步伐】+ 第一幕【绝望的泥沼与奇迹降临】  场景 1-3
- 第2集_城市谋生   第二幕【城市谋生与惊艳四座】                          场景 4-6
- 第3集_全网爆红   第三幕【技能爆发与全网爆红】                          场景 7-9
- 第4集_衣锦还乡   第四幕【衣锦还乡与技艺觉醒】+ 片尾钩子【改写命运的竹篾】 场景 10-13

【主要人物】（据剧情）
- 苏小七：17 岁高考落榜农村女孩，绑定"进步系统"（走路赚钱）后逆袭，戴黑框眼镜、清秀。
- 苏父（苏有福）：跛脚，编簸箕为生，憨厚省俭。
- 苏母：操持家务、卖猪凑学费。
- 林闵：考上重点大学的邻居少年，内心阴郁后被小七温暖。
- 梁女士：富太太，雇小七做家教。
- 梁佳佳：梁家叛逆少女，后成小七的网络推手。
- 张娟：小七同学，打扮妖艳、炫富。

# 步步生金 · 世界观

## 一句话故事
高考落榜的农村女孩苏小七绑定"走路赚钱"的**进步系统**，靠每一步攒下的钱与系统奖励的技能一路逆袭——从给家人添衣置物到竹编技艺惊动非遗、全网爆红，改写一家人的命运。

## 时代 / 地域
- **当代中国**（现代都市 + 乡村并存）。一头是贫穷的山村（苏家：泥砖房、糊塑料布的窗、编簸箕为生），一头是繁华城市（商场、医院、图书馆、富人公寓）。
- 题材：青春 / 奇幻 / 逆袭 / 亲情。基调**明亮温暖、积极向上**，是一部"爽剧"——不悲情、不黑暗，苦难是底色，逆袭与亲情是主旋律。

## 核心规则：进步系统（轻奇幻设定）
一套绑定在主角身上的"金手指"系统，以**半透明科技感 HUD 面板 + 系统机械音**呈现，叠加在写实画面上：
- **走路赚钱**：每走一步获得现金，面板实时跳动"步数 / 余额"。
  - 一级系统：每步 0.1 元，一万步封顶。
  - 二级系统（扶老人后升级）：每步 0.2 元，每日两万步封顶。
- **行善 / 努力升级**：做好事（扶老人）、读书努力会触发系统升级或奖励。
- **技能卡奖励**：阅读相关书籍可获得技能卡——记忆力 buff、英语语感 buff、竹编技能卡（入门/白金）、力大无穷卡等；技能卡能让宿主（或被指定的人）瞬间掌握技艺。
- **可指定他人**：高阶用法可"指定某人使用技能卡"（结局小七指定父亲使用竹编白金附属卡，让父亲技艺觉醒）。
- **蝴蝶效应 / 高阶系统**：宿主引发重大文化传承影响后，解锁更高阶财富系统（片尾钩子）。

> 系统是"奇幻"的唯一来源，其余一切写实。系统视觉要**克制**：发光面板/UI 警报点到为止，不喧宾夺主。

## 基调 / 画风定位
- **写实真人电影感** + **轻奇幻系统 HUD**。明亮温暖、自然光为主（乡村暖金夕照、城市清透日光）。
- 情感主线：**亲情**（父亲编簸箕的伤痕手、母亲卖猪凑学费）+ **逆袭爽感**（余额飙升、技惊四座、全网爆红）。
- 反塑料感：真实胶片颗粒、实景光、真实皮肤/布料/竹篾质感——不是 3D/CG/动画。

## 主题
"步步生金"——一步一个脚印的努力终会改写命运；财富与技艺的尽头是亲情与文化传承（竹编非遗）。

# 《巴别塔 / Babel》场景设定

> 人读 · 设计。每场景：环境 / 氛围 + look 清单（打光 / 状态变体）。视觉规格与 `bible.json` 一致（以 json 为准）。
> 立场景判据：凡分镜头会**给到镜头**的地点就立一个 `scene`——哪怕剧本一句带过，只要会出画。

---

## 1. 废土黄昏外景  `wasteland_exterior`
- 出现集：第1集_开篇
- 环境 / 氛围：外景、黄昏。无尽黄沙的末世地球；人类文明残存的泥像与断壁残垣，烟雾伸向天际。**残存的巨大"人脸山"**矗立其间——人类骄傲文明的墓碑。一艘神似宇宙飞船的诺亚方舟轰鸣驶来，近未来科幻线条 × 末日废土。
- 视觉参考：《沙丘》沙海地平线 + 暮色尘霾。
- look 清单：
  - `dusk`（基础，第1集）：黄昏暖橙偏冷的逆光，大气尘霾，长长的阴影；史诗般空旷压抑。
- 来源依据：原文"外景。残存的巨大人脸山和末世地球。黄昏。无尽黄沙…泥像断壁残垣，烟雾伸至天际。一艘神似宇宙飞船的诺亚方舟轰鸣驶来"。

## 2. 诺亚方舟内部大厅  `noah_ark_hall`
- 出现集：第1–4集（全剧主舞台）
- 环境 / 氛围：内景。方舟/宇宙飞船内部大厅，空旷寂寥。近未来科幻 + 东方禅意极简：高处有领航员静坐的位置/平台，巨大的玻璃舷窗望向死寂的地球，四周是乘客的隔间舱室、仪表盘（红灯闪烁）。气质冷峻、压抑、密闭。是"缩小的巴别塔"。
- 视觉参考：《星际穿越》舱内冷光 + 诺亚方舟意象 + 东方禅意压抑。
- look 清单（打光 / 状态变体，跨集变化）：
  - `dim`（基础 / 第1–2集）：空旷昏暗、情绪化；冷光来自巨大舷窗外死寂的地球；高处静坐位、抬升的平台。
  - `night`（第3集_抉择）：夜。**舱窗外月光是唯一光源**——冷蓝月光切割密闭空间，阴影浓重，猜疑紧绷。
  - `flickering`（第4集_倒塌）：行驶中**灯光忽明忽暗、像在苟延残喘**；明灭不定的舱内光，三声枪响的密闭惊悚，烟硝与血色。
- 来源依据：第1集"内景。诺亚飞船内部大厅…静坐在高处，看着玻璃窗外…整个诺亚飞船空旷寂寥"；第3集"夜。舱窗外月光是唯一光源"；第4集"灯光忽明忽暗，像在苟延残喘"；第2集仪表盘红灯闪烁。

## 3. 机器人世界的巴别塔  `robot_babel_world`
- 出现集：第4集_倒塌（结局，一句带过但会出画）
- 环境 / 氛围：方舟驶入的**巨大的、由机器人建造的、没有人类的世界**——一座**真正的巴别塔**。冷峻、宏伟、非人；机械造物的几何尖塔刺向天空，没有任何人类的痕迹。是全片母题的终极显形与反讽落点。
- 视觉参考：《沙丘》宏伟非人建筑尺度 + 赛博机械都市 + 巴别塔垂直意象。
- look 清单：
  - `default`（第4集结局）：宏大冷峻、机械几何的巴别塔与机器人都市，灰金属冷调，空无一人。
- 来源依据：第4集结尾"随后飞船驶入巨大的由机器人建造的、没有人类的世界。一座真正的巴别塔"。

## 道具一览（详见 bible.json，环境内出现）
- `handgun` 手枪：K 的旧枪，全剧三声枪响的凶器（第3–4集）。
- `glass_heart` 玻璃盒心脏：机器僧胸腔内、玻璃盒装的仍在跳动的人类心脏，"人类希望"的载体（第4集特写·反转）。
- `cryo_med_box` 冷冻药剂盒：座位下取出的冷冻小盒，内装各种药剂/营养液，K 用它给机器僧补充营养液维持心脏（第4集）。
- `mirror` 小镜子：女人随身的镜子，倒塌段她"盯着镜子，补着已经不存在的妆"（第4集；第2–3集可随身）。

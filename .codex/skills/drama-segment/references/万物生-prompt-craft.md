## 一、手艺 DNA：万物生提示词的 7 个核心技法

每个技法附 **mini 片段**（从真实万物生提示词截取、已清洗）。④ 写任何档位的提示词都应能命名自己用了哪几个。

### 1. 逐镜画面空间分层（前景 / 中景焦点 / 背景）

每个镜头不是一句扁平描述，而是**分前/中/后景写**，明确谁清晰、谁虚化。这是万物生最显著的密度来源。

> 「画面底部前景是江流的局部躯干以**虚化模糊**状态出现+仰躺在甲板上+只可见局部身体如肩膀/胸部/上臂+躯干作为画面底部前景框架元素+面部不入画+呈柔和模糊的浅景深处理。
> 画面中景焦点位置：副手以单膝跪姿蹲在江流身边+位于画面中部偏一侧+**焦点清晰锐利对焦**+高马尾辫子+部落红丝带头饰+脸部刀疤+赤膊深棕皮革背心可见。背景是船的甲板。」
> ——废土沙艇·镜头1

要点：前景虚化框架 → 中景焦点主体 → 背景交代环境，三层永远清楚。**标准档每镜也要有这个**——哪怕只用一句话点明"前景/焦点/背景分别是什么"。

### 2. 镜内三段编舞（开篇→中段→末段）

一个有内部转折的镜头拆成**三个动作阶段**，每段有具体的动作 beat + 物体/视线变化 + 台词卡点。不是一句"副手找到邀请函交给刘回"——而是逐帧编排。

> 「镜头开篇阶段：副手的一只手伸到江流的衣服身上+手指在酒红色皮革背心位置探寻+然后手抽出+手中握着一张皇帝邀请函+伴随布料摩擦声+邀请函从衣物滑出的细微声响。
> 镜头中段阶段：副手将邀请函举到面部附近短暂看一眼+然后抬头向画面右上方画外看+暗示画面外有人+开口说话……
> 镜头末段阶段：副手保持视线朝向画面右上方+手臂前伸+邀请函向画面外移动+末帧保持手臂前伸状态。」
> ——废土沙艇·镜头1

要点：每段一个核心动作 beat；动作与台词**卡点**精确到帧。**只有满配档需要三段编舞**——标准档只需一条画面构图+动作描述。

### 3. 台词三件套（原话 + 怎么念 + 卡点）

万物生逢台词必写三层：①原话一字不动 ②怎么念（嗓音+语气+节奏+「不是什么」）③卡点（说到哪个字时画面发生什么）。

> 「大声呼喊:"够了!把那只青铜兽拆了!"——这一句是中年男性沉稳但带着突然爆发的不耐烦+前一句"够了"是从喉咙挤出的低沉怒喝+后一句"把那只青铜兽拆了"是命令式的果断短促+整体语气是上位者突然失去耐心的命令+嘴部口型与呼喊词同步+呼喊到"拆了"两个字的瞬间相机即将开始甩镜。」
> ——废土沙艇·镜头2

> 「丹眉对着手机小声说（声音不大+懒洋洋+平直陈述+无情绪起伏+完全 deadpan）："喂，我到巽位了，然后呢？"」
> ——儿童剧场·镜头4

要点：**台词语言跟剧本原语言走，一字不改**；"不是兴奋+不是惊讶+是…"的否定描述帮模型避开最常见的错误情绪；卡点把台词和画面动作绑在一起。满配档台词三件套全写；**标准档至少写原话+怎么念**。

### 4. 声音底层设计（环境声铺底 + 事件音 + 显式否定）

不是"配乐：紧张"——是**具体到物理声源**的声音设计，且**显式否定**不要什么。

> 「全段持续背景铺底——香港铜锣湾真实繁华街道环境声混合层：多辆出租车引擎怠速和加速声+多辆叮叮电车在不同距离的"叮叮"铃声叠加+密集人群整体低频嗡鸣+多种鞋底踩人行道不同节奏脚步声"啪嗒哒哒"+远处车流低频轰鸣+店铺音乐碎片。**这些环境声占据音轨主体填满整个空间感**。」
> ——铜锣湾跟拍

> 「用白噪音和动作音效作为整段声学底层+**不要配抒情背景音乐**+不要任何鸟啄声或螃蟹哀嚎声(后期音效自行叠加)。」
> ——废土沙艇·声学底层

要点：环境声铺满空间感 → 事件音叠上去 → **明确说不要什么**（不要配乐/不要某个声音）。

### 5. 物理可信的相机（机位 / 高度 / 焦段 / 微抖）

相机不是抽象的"近景"——是一台**放在具体位置**的物理机器。

> 「中景+焦段50mm定焦镜头+直线校正镜头投影+相机位置基本平视高度或略微仰拍角度从地面附近向上看+相机大致静止+叠加手持微抖呼吸感+构图非居中。」
> ——废土沙艇·镜头1

> 「全程迎面退拍的反向跟拍镜头，稳定器架设。镜头位于丹眉正前方约3-4米距离的人行道上，丹眉始终朝镜头方向走来，镜头持续向后退保持恒定3-4米距离。镜头水平高度在丹眉腰部位置略低。」
> ——铜锣湾跟拍

要点：焦段+投影+相机物理位置+运动方式+微抖/稳定器——写全才能让模型"像真拍"。**标准档至少写景别+焦段+机位高度+运动方式**。

### 6. 负向约束（严禁 / 不要 / 不可）

模型最容易在你没写的地方自由发挥。万物生**到处**是负向约束。

> - 「**严禁侧卧**」——锁定仰躺姿态
> - 「**禁止萌螃蟹和鸟龙入画**」——本镜只有副手和江流
> - 「**不要配抒情背景音乐**」——声音底层只要白噪音+动作音效
> - 「绝对**不要把镜头推近**到只能看到她的胸以上」——锁定全身取景比例
> - 「**不是兴奋+不是惊讶**+是部落女副手对老大汇报任务结果的平稳语气」——台词情绪否定锚
> - 「严格保持球体形态**不可弹开变形为螃蟹形态**」——锁定变体状态

要点：**每个容易出错的地方都显式否定**。满配档集中写在组末的"负向约束"段；标准档散在各镜画面描述里（像"禁止X入画""不要配乐"）。

### 7. 末帧状态锚定（这一帧定格在什么状态）

精确描述镜头最后一帧的画面——它是下一段的首帧衔接点。

> 「末帧副手保持手臂前伸的状态+邀请函即将传递到画面外的接收方+副手台词的尾音"邀请函"在末帧前完成。」
> ——废土沙艇·镜头1

> 「定格在被刘回呼喊吓到的呆滞状态+整个画面保持静止+绝对死寂+只有非常微弱的大漠风声呼啸残留。」
> ——废土沙艇·镜头3

要点：精确到"什么姿势/什么表情/什么声音留在画面上"。满配档必须有；标准档的关键承接镜也应有。

## 三、档位密度校准（④ 写完后对照）

> 当前 skill 强制满配：只使用下表“满配”行作为验收标准；标准/精简行仅作历史参考。

| 档位 | 字数参考(单组15s) | 必须有的手艺 | 可以没有 |
|---|---|---|---|
| **满配** | 3000-5000字 | 空间分层(前/中/后景×对焦) + 三段编舞(有转折的镜头) + 台词三件套(含卡点) + 声音底层(含否定) + 物理相机(焦段+投影+位置) + 负向约束(集中段) + 末帧锚定 | — |
| **标准** | 1200-2500字 | **每镜画面构图(含空间层次)** + 台词三件套(至少原话+怎么念) + 声音底层 + 物理相机(至少景别+焦段+运动) | 三段编舞(动作简单时不用) · 末帧锚定(非承接关键镜时不用) · 集中负向约束段 |
| **精简** | 400-1200字 | 时间码/镜头分段 + 核心动作 + 关键音效 + 视觉风格 | 空间分层 · 三段编舞 · 台词三件套 · 末帧锚定 |

### 标准档的底线（最重要的一条）

> **标准档每镜必须有一条画面构图描述，包含空间层次（谁在前景/中景/后景、谁清晰谁虚化）。**
> 如果你写的标准档是"每镜一句话"——太薄了，回去加。万物生即使最轻的镜头也有空间交代。

### 满配档的封顶

三段编舞只给**内部有动作/情绪转折**的镜头用——静镜别硬拆成三段。色卡 HEX 不写（那是 ⑤ 的事）。

## 四、语言纪律

- **导演语**：中文（万物生的导演指令都是中文）
- **镜头术语**：留惯用英文（HARD CUT / whip pan / shallow depth of field / anamorphic / pan / zoom in / close-up / deadpan / static / handheld 等不翻译）

- **STYLE LOCK**：从 bible 原样取，不改语言

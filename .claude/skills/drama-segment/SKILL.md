# Drama Segment（分段 + 蓝图）

像专业导演 + 分镜师 + 调色师，把单集切成 **segment**，并为每段画出**一段一张的手绘草图分镜板**（一段 = 后续一次 SD2 视频生成）。本环节**一手包办编辑层（分什么镜、怎么调度）+ 渲染层（模型该怎么渲染）**，产出**草图板 / 色卡 / staging + 段提示词**四件视觉蓝图。流水线契约见 `docs/流水线设计.md`。

**核心模型**：草图分镜板把段内**机位 / 硬切 / whip pan / 180°轴 / 构图**显式画给视频模型（远胜纯文字），所以**一段可含段内硬切、一次生成**。"镜"= 草图板里的"格"；网格≈镜数（2x2=3镜+plan / 2x3=5镜+plan / 3x3=8镜+plan）。

## 动手前先读（参考库，按需取）
- 切段 / 镜头语言（三层技法库，严格选库）：[`references/vol1-类型场景.md`](references/vol1-类型场景.md)（戏类型框架）→ [`references/vol2-对话功能.md`](references/vol2-对话功能.md)（对话功能）→ [`references/vol3-技术工具.md`](references/vol3-技术工具.md)（技术工具，可叠多条）。
- 段 prose 手艺范本（密度标尺）：[`references/万物生-prompt-craft.md`](references/万物生-prompt-craft.md) + [`references/sd2-render-spec.md`](references/sd2-render-spec.md)。
- 三套蓝图模板（参数化，本环节核心）：[`references/sketch-storyboard-template.md`](references/sketch-storyboard-template.md)（草图板·核心）、[`references/color-card-template.md`](references/color-card-template.md)（色卡）、[`references/staging-diagram-template.md`](references/staging-diagram-template.md)（俯视staging）。

## 输入
- 单集剧本 `docs/scripts/<剧名>/<第N集_*>/…txt`。
- `docs/scripts/<剧名>/bible/bible.json`——读 `style_lock`（原样用）、`assets[]`（人物 `intent.sheet_spec` 取外观要点写本段主体 + 草图板一致性约束；场景 `spec_prompt`/`factions`）、`ref_token`。
- `docs/scripts/<剧名>/assets/`——**上游已生成的角色参考表 / 场景板 / 道具图**（草图板生成时按需当 ref；锚定清单解析路径）。**前置硬依赖**：库资产必须先于本环节（草图板要画已生成的人物；段里出现的道具/HUD 要先出好资产，再喂本环节生成草图板保一致——否则板里会乱编，如 HUD 文字跑成英文）。
- 兜底：无 bible→提示先建全剧设定；库资产没出齐→可先出分段计划 + prose（文字），蓝图图等资产补齐再出，并点名缺哪些。

## 4a 分段（segment 切分）
- **一段 = 一个连续戏剧节拍**（同一地点-时间、一段动作/对话回合），段内 **3-4 镜、~12s**；边界在 **场景/地点/时间/节拍切换** 处。一集大致切 ÷12s 段（如 ~105s→~10 段）。
- 用三层技法库**严格选库**写镜头语言（落地调度、非只挂标签）：戏类型①×对话功能②×技术工具③ 叠加落进每镜的景别/运镜。
- 每段定：**镜序、各镜时长**（0.5s 增量，单镜 0.5-10s，段总 ~12s）、**段内硬切 / whip pan**（哪两镜之间切）、**180°轴**（动作轴、机位守哪侧防跳轴）、**站位**、**出场资产**（用 bible 名 + ref_token）、**戏剧属性**（重点/常规/过场，仅用于调度优先级与报告，不用于降档）。
- **镜号每段独立从 1 数（铁律）**：每段=一次独立视频生成，所以**段内镜号从 镜头1 重新起**（SEG-1A 镜1/2/3、SEG-1B 镜1/2/3、SEG-2A 镜1/2…），**绝不跨段连续编号**（不要 SEG-1B 接成镜4/5/6）。这与"一段=一条独立片段"一致。
- **段内硬切是允许的**（蒙太奇、正反打）——由草图板显式画出，让 SD2 照切。无内部硬切的连续运镜段同理一张板。
- 台词/VO **保留剧本原语言**，一字不改；镜头时长要覆盖台词念完。
- 写 `分段计划.md`（含全集分段总览表：段/段名/场景/镜数/时长/戏剧属性/提示词档位=满配/段内硬切）。

## 4b 每段视觉蓝图（三套模板 → generate_images.py，category=scene，16:9）
对每段产：
1. **色卡 `@[palette:<id>]`**（[color-card-template](references/color-card-template.md)）：13色HEX，按"光+主体材质+场景主色+特征色+暗部"凑；色值复用 bible style_lock 调性 + 本段场景/出场资产材质。**按场景复用**（同场景多段共一张，id 如 `ep1_s1_dusk`）。
2. **俯视 staging `staging_<段>.png`**（[staging-diagram-template](references/staging-diagram-template.md)）：**仅多人/复杂调度段**才出（单人简单段省略——草图板里的 Shooting Plan 格已覆盖俯视机位）。**出了 staging 的段，草图板要 ref 它**（见下），所以 **staging 必须先于草图板生成**。
3. **草图分镜板 `@[board:<seg>]`**（[sketch-storyboard-template](references/sketch-storyboard-template.md)·**核心**）：手绘铅笔、**纯白纸**（做旧泛黄牛皮纸有偏色污染风险，配色只由色卡定）、N格=段内镜数 +1 Shooting Plan 格；每格画该镜构图/机位/动作，caption 写 焦段/SFX/台词原文/动作，红笔标 运镜/硬切/whip pan/180°轴；逐角色一致性约束取自 bible `sheet_spec`（发须/服装/signature）。
   - **草图板生成时喂的 ref（按需，都走 generate_images.py 编辑模式）**：
     - **本段有 staging 图 → 一并 ref staging**：让板的机位/180°轴/站位与调度图一致（两者都是手绘铅笔线稿，互参不串色，干净）。
     - **段里有道具/HUD/特定UI（如进步系统面板的中文"步数/余额"）→ ref 该道具的库资产图**：板里该元素就一致（中文/造型对）；约束"只copy其内容/文字、画成铅笔线稿、不带入其颜色，保持铅笔白纸"。
     - 角色长相默认靠 `sheet_spec` 文字约束（铅笔板 gestural，不强求锚角色表图；真要更锁可加角色表 ref，但当心 photoreal 把铅笔板带偏）。
   - **生成顺序**：色卡 → staging（若有）→ 草图板（最后，才能 ref staging + 道具）。
   - 画幅：草图板整图 16:9（或多镜用 21:9）；**每格的子画幅跟成片**（成片 16:9 横屏→每格横框；竖屏短剧→每格 9:16 竖框）。
> 蓝图图都走**共享的多渠道图像生成工具**（与库资产同一个 `generate_images.py`，micu→packy→moyu；当前路径 `.claude/skills/drama-asset-gen/scripts/generate_images.py`），`--tasks` 传填好的模板 prompt、`category:"scene"`、`--output-dir <集>/分段`（落到 `分段/scenes/`）。

## 4c 段级 prose（自包含 + 显式 @资产锚定，写进 `*_段提示词.md`）
**每段 = 一段自包含提示词，必须保留 `[资产锚定]` 块显式 @锚所有资产**——草图板/色卡只是把"场景+站位+配色"换了承载方式，prose **照旧锚定资产**（这块同时就是下游拼 SD2 请求时的有序 reference_image 清单，不锚就不知道往请求挂哪些图）。每段固定五块结构：

```markdown
## 第N段 SEG-XX｜段名　[档位：满配]
镜头数：M个｜总时长：Ns｜戏剧属性：重点/常规/过场｜提示词档位：满配

[风格锁定]
<bible.style_lock 全文，原样照搬，全集每段同一段>

[资产锚定]（= 送 SD2 的参考图集；只列真送进去的资产，不写解释/不写"不锚X因为…"）
@[board:<seg>] 作为本段分镜构图/机位/硬切/运镜的主引导（永远第1）。
@[palette:<id>] 作为本段配色锚定。
@[char:<id>|look] 作为〈角色名〉的视觉锚定——<外观要点取自 sheet_spec + 本段状态>。
@[prop:<id>] 作为〈道具名〉的视觉锚定。
<@[scene:<id>|look] 仅在需要时锚——见下「场景按需」>

[本段 Ns，M镜，按下文执行]
镜头1（Xs，景别+焦段+镜头投影+机位高度+运动+微抖+构图非居中）：
画面构图：画面前景是<X，虚化模糊/框架元素>+中景焦点是<Y @[char:..]/@[prop:..]，焦点清晰锐利对焦+外观要点>+背景是<Z，环境>。<谁清谁虚写明>。
镜头开篇阶段：<动作beat A+B+C @[prop:..]+物体/视线变化+声音>。镜头中段阶段：<…+台词卡点>。镜头末段阶段：<…+末帧锚定>。
（**镜内内联锚**：把出现在该镜的人物/道具的 @token 顺手贴在它在画面里的位置上，让模型把"哪个资产"绑到"哪一刻"，见下「镜内内联锚」）
镜头2（…）：…

[声音设计]
<环境音底层 + 音效卡点 + 念白；声音否定（如"仅环境音效，无背景音乐/无多余人声"）>

[关键约束]
<画风/影调重申 + 非3D/CG/塑料/动画 + 无字幕无水印 + 本段特定约束（如"脸不入画"）>
```

- **`[资产锚定]` 块 = 锚定清单**：逐条列本段真送 SD2 的 @token，**`@[board:]` 永远第1**（构图主引导），再 `@[palette:]`色卡 → `@[char:]`人物（在画面里露脸/露身才锚）→ `@[prop:]`道具 →（按需）`@[scene:]`场景。顺序 = 下游送 SD2 的 reference_image 顺序，与 `资产绑定.json` 的 `ref_set` 一一对应。
- **SD2 锚定预算（铁律）**：每段（=一次 SD2 请求）**图片资产 ≤ 9 张（去重）、视频 ≤ 3 条、音频按需**。这是上限不是目标——但**预算内尽量多锚有用的**（见下"镜内内联锚"）。超 9 张按 board→人物→道具→色卡→场景的优先级截断。
- **场景按需锚（去噪，重要）**：`@[scene:]` 空场景板**不是默认必锚**——草图板已带场景构图、prose 已写环境，**紧镜/特写/人物或道具占满画面的段（如 ECU 脚、过肩双人）不要锚场景**（送进去对画面无帮助、还稀释主体、白占预算=噪音）。**只在"环境本身是主体"的大全景/establishing 段才锚场景**。同场景的相邻独立段，各自按这条单独判断，不要因为"上段锚了"就跟着锚。
- **镜内内联锚（用满预算）**：除顶部 [资产锚定] 块外，**在逐镜 prose 里把该镜出现的人物/道具 @token 顺手内联**贴到它在画面的位置（如`中景焦点是苏父 @[char:su_father|look:default]+...递出新手机盒 @[prop:smartphone]`）。让模型把"哪个资产"绑到"哪一镜哪一刻"。内联的 token 必须也在 [资产锚定] 块里（同一套去重资产，不超 9 张）。
- **prose 不写元注释（去噪，重要）**：段提示词是送模型的，**不要混入规划自语**——如"（留到1B揭脸再锚）""（本段不锚人物表因为…）""（与上段同色卡）"这类**对模型完全没用、反而是噪音的解释话一律删掉**。只写画面/动作/表演/台词/声音/约束本身。要解释设计意图，写到 `资产锚定方案.md`（人读），不进 prose。
- **密度铁律（关键，照万物生范本）**：草图板与 prose **双写构图**——板给 SD2"看"构图，prose 仍照万物生**逐镜写空间分层（前景/中景焦点/背景 × 谁清晰谁虚化）**加固（万物生最显著的密度来源，连最轻的镜也要有空间交代）。**别因为有草图板就把构图从 prose 砍掉。**
  - **"+"链流式密集 prose**：照万物生原文体例，一个 beat 接一个 beat 用"+"串成密集长句（如`手伸到衣服上+手指探寻+手抽出+握着邀请函+伴随布料摩擦声`），**不要拆成 markdown 要点**。
  - **禁自造字段**：只用万物生有的层（画面构图/三段编舞/台词三件套/声音/末帧锚定）；**不要发明"重心""要点"之类范本里没有的标签行**。
  - **强制满配档**：所有 segment 的 `段提示词.md` 都按满配 3000-5000字/段写；必须包含空间分层+三段编舞+台词三件套含卡点+声音底层含否定+物理相机焦段投影位置+负向约束+末帧锚定。即使该段戏剧属性是“常规”或“过场”，也不得降为标准/精简；若确实是黑场/纯转场，也用满配方式写清镜头开篇/中段/末段、声音、约束和末帧。
- **不再按分量降档**：4a 的重点/常规/过场只记录戏剧属性和调度优先级，**不决定 prose 档位**。写完对照 `references/万物生-prompt-craft.md` §满配范例自检密度，低于 3000 字或缺任一满配要素就回去加。
- 首帧意图写进逐镜（"以草图板某格构图为开场"），**不用 moyu 排他的 first_frame**（那样只能塞1张参考图）。
- 台词/VO 用剧本原语言；术语留英文；STYLE LOCK 原样取 bible。

## 4d 锚定（让四件套能拼成 SD2 请求）
新增两个 ref_token 类型并注册：**色卡 `@[palette:<id>]`、草图板 `@[board:<seg_id>]`**（段 id 如 `ep1_1A`）。
- 写 **`资产锚定方案.md`**（人读）：ref_token 体系（char/scene/prop/palette/board）+ 片段资产↔token↔路径表 + "两处用到锚定"（①生成草图板时用 prop 资产做 ref 保一致 ②拼SD2时按锚定清单解析）+ SD2 拼装逻辑。
- 每段定**锚定清单**=送 SD2 的**有序 reference_image 集**：`@[board:]`**永远第1（构图主引导）** → `@[char:]`人物（露脸/露身才锚）→ `@[prop:]`道具 → `@[palette:]`色卡 →（**按需**）`@[scene:]`场景（紧镜/特写段不锚，见 4c「场景按需」）。**去重后 ≤ 9 张图片 / ≤ 3 视频 / 音频按需**；预算内尽量多锚有用的。写进段 prose 该段 [资产锚定] 块，也写进机读 `资产绑定.json` 的 `ref_set`（两处一一对应）。
- 写 **`资产绑定.json`**（喂下游视频请求环节）：
```json
{
  "drama":"<剧名>","episode":"<集>",
  "assets": { "@[board:ep1_1A]":"<集>/分段/scenes/SEG-1A_草图板.png", "@[char:su_xiaoqi|look:default]":"assets/characters/苏小七.png", "@[palette:ep1_s1_dusk]":"<集>/分段/scenes/色卡_石板路黄昏.png", "...":"..." },
  "segments": [
    { "seg":"SEG-1A","title":"魔鬼的步伐","scene":"乡间石板路·黄昏","duration_s":12,"ratio":"16:9",
      "prose_ref":"分段/段提示词.md#SEG-1A",
      "ref_set":[
        {"token":"@[board:ep1_1A]","role":"storyboard","why":"构图/机位/硬切(主引导)"},
        {"token":"@[palette:ep1_s1_dusk]","role":"palette","why":"配色"},
        {"token":"@[prop:white_sneakers]","role":"prop","why":"主体"}
      ] }
  ]
}
```
- `ratio` 跟成片；`duration_s`=段时长；`ref_set` 顺序 = 送 SD2 的 reference_image 顺序（板第1）。

## 语言纪律

## 规则

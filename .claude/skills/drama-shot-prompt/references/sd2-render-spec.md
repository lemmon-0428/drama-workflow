## ① 分层骨架：5 内核 + 5 增强

一条 SD2 提示词由这些层组成。**内核**几乎每条都有；**增强**按档位开关（见②）。

**内核（标准档就铺满这五层）**
1. **风格锚 STYLE LOCK** —— 全剧统一的渲染风格（见④），每组复用同一段。
2. **资产锚 @[]** —— 把每个人物/场景/关键道具 pin 到参考图（见③）。**跨镜不崩脸/不崩景的头号手段，最重要的一层。**
3. **机位** —— 景别 + 运镜（沿用③）+ 焦段建议 + 构图（前/中/后景、谁清晰对焦）。
4. **声音底层** —— 对白/VO/音效；说明配不配乐。
5. **台词** —— 该镜要说的话（沿用③，一字不丢）。

**增强（按档位叠加）**
6. **分段时间线** —— 把一个镜头拆成 开篇→中段→末段 编舞（动作/视线/台词卡点）。
7. **念白指导** —— 台词"怎么念"（语气/嗓音/情绪 + 不是什么）。
8. **HEX 色卡** —— 关键镜锁色（仅当 bible/分镜给了调色）。
9. **负向约束** —— 明确"不要什么"（谁别入画/形态别变/别配乐…）。
10. **转场标记** —— HARD CUT / WHIP PAN 等。

## ② 三档模板（由③的「分量」决定，默认标准档）

| ③分量 | ④档位 | 铺哪些层 |
|---|---|---|
| 过场 | **精简** | 风格锚(共用) + 资产锚 + 一句画面/动作 + 声音 |
| 常规（默认） | **标准** | 内核五层（风格锚+资产锚+机位+声音+台词） |
| 重点 | **满配** | 内核五层 + 分段时间线 + 念白指导 +（有则）HEX + 负向约束 + 转场 |

### 精简档（过场）—— 别花力气
```
## 第N组｜组名　[档位：精简]
镜头数：X｜总时长：14s｜分量：过场
资产锚：@[scene:noah_ark_interior_hall|look:dim]　诺亚方舟内部大厅·幽暗——严格按参考图渲染空间/舷窗冷光；本组全程
视频提示词：
镜头6（3s，特写，俯拍）：机器僧金属手指在膝上规律微动如在计算，关节齿轮隐转，红袈裟一角入画；浅景深，铜铁反光在幽暗中明灭。音效：极轻齿轮咔哒声。
```

### 标准档（常规·默认）—— 内核五层
```
## 第N组｜组名　[档位：标准]
镜头数：X｜总时长：15s｜分量：常规
资产锚：
  @[char:navigator_k|look:default]　领航员K——严格按参考图渲染五官/炭灰长袍领航装；出现镜3-4；状态：静坐高台、侧对舷窗
  @[scene:noah_ark_interior_hall|look:dim]　诺亚方舟内部大厅·幽暗——严格按参考图渲染空间/舷窗冷光；本组全程
主体：领航员K、机器僧　｜　场景：诺亚方舟内部大厅·幽暗
空间站位：K 右上高台侧对舷窗，机器僧左下盘坐，舷窗后景冷光
视频提示词：
镜头3（4s，大全景，极缓推）：切入空旷大厅，舷窗外死寂地球；K 静坐右上高台侧对舷窗，机器僧披红袈裟左下盘坐，相机极缓前推。舷窗冷光为唯一主光、舱内幽暗。K（VO，沙哑）："God said, let there be light. Then He took away human language,"
镜头4（4s，中近景，固定）：K 侧脸望舷窗外文明残骸，眼神像熄灭的火山，几不可察皱眉。侧逆光勾轮廓、半张脸沉入暗影。K（VO，承接念完）："thinking that would stop the Tower of Babel. But He was wrong."
```

### 满配档（重点）—— 内核 + 全增强
（示例取自第4集 K 掀胸反转，演示结构）
```
## 第N组｜真相掀开　[档位：满配]
镜头数：1｜总时长：5s｜分量：重点
资产锚：
  @[char:navigator_k|look:chest_reveal]　领航员K——严格按参考图渲染掀开衣襟露铁灰机械胸腔+缠绕电线；全程；状态：站立、衣襟撕开
  @[scene:noah_ark_interior_hall|look:flickering]　大厅·灯光忽明忽暗——严格按参考图；本组全程
主体：领航员K　｜　场景：诺亚方舟内部大厅·忽明忽暗
空间站位：K 居中半身，机械胸腔正对相机
视频提示词：
镜头N（5s，近景，极缓推）：
  · 开篇：K 双手扣住衣襟、停顿半拍；灯光暗下又亮。
  · 中段：K 猛地撕开衣襟，露出铁灰机械胸腔与缠绕电线；相机微微前震。台词（K，沙哑自嘲）："我也被诅咒——我们都是。"——念白指导：低沉、近耳语、带笑意的疲惫；不是愤怒、不是悲怆；说到"我们都是"气声更弱。
  · 末段：K 抬眼直视镜头，嘴角扯出一丝笑；定在这一帧。
  · 转场：HARD CUT
负向约束：机械胸腔严格按参考图、别长出皮肤；除 K 外不入画；不要配乐，只留电流嗡鸣。
```

## ③ 资产锚 @[] 写法（符号槽位，⑤ 解析）

格式：`@[<kind>:<id>|look:<look>]`，kind ∈ `char` / `scene` / `prop`（prop 可省 look）。

**id 与 look 从 bible 取**：用③写的 display_name 在 `bible.assets[]` 里匹配到资产；同名多条时选 `intent.planned_episodes` 含**本集**的那条 look。**直接用它的 `ref_token`**（已是 `@[kind:id|look]`）。后接：display_name —— 严格按参考图渲染&lt;要点&gt; + 出现：镜X[-Y] + 状态：…

例：
- `@[char:navigator_k|look:default]`（领航员K·第1集）
- `@[char:navigator_k|look:chest_reveal]`（第4集反转）
- `@[scene:noah_ark_interior_hall|look:dim]`（第1集大厅）
- `@[prop:handgun]`（手枪）

这些是**符号槽位，不是真图**——④ 只写 id+look，真实参考图由 ⑤4b 按 `assets/asset_registry.json` 解析或生成。这正是 ④→⑤ 的契约（标杆作品里也用 `@[{INVITATION_LETTER_ID}]` 这种占位符）。**只要 id/look 写对，下游就能锚。** 某对象 bible 里查不到 id（如③临时点名的小道具）→ 用 `@[prop:中文名]` 占位并在组末注明"待 bible 补录"。

## ④ STYLE LOCK 写法（从 bible.style 来，全剧常量）

读 `bible.json` 的 `style`，渲成一段 STYLE LOCK，放在 `镜头提示词.md` **顶部一次**，全集每组复用同一段（它是 per-drama 常量，跨集必须一致）。组成 = bible.style 精髓 + 反塑料感锚（见⑥）。

巴别塔示例（顶部一次）：
```
[STYLE LOCK]（全集统一·每组复用）
8K 超写实真人电影感 / photoreal live-action cinematic；《沙丘》《星际穿越》级质感 + 东方禅意压抑；废土美学 × 心理惊悚 × 赛博科幻。
质感锚：真实电影胶片颗粒 + 实景光 + 高光轻微光晕 + 大气尘霾 + 可触实体材质；照片级电影定格、透过镜头拍到的真实物理场景——不是 3D 渲染、不是 CG、不是塑料感。
```
若 bible 日后有专门的 `style_lock` 整段，**原样照用**，别再自行扩写。

## ⑤ 增强层细则（满配档才铺）

- **分段时间线**：把镜头拆 开篇→中段→末段，每段写 动作+视线+（该段的）台词+卡点（"说到 X 的瞬间相机 Y"）。**只对内部有动作/情绪转折的镜头用**；静镜别硬拆成三段。
- **念白指导**：每句要紧台词补"怎么念"——语气/嗓音/情绪 + **不是什么**（"不是兴奋、不是愤怒"）。这是让台词有灵魂的关键，标杆作品逢台词必写。
- **HEX 色卡**：仅当 bible/分镜给了明确调色才锁（`所有色彩按色卡执行+不偏离`）；没有就别编色值。
- **负向约束**：写清"不要什么"——谁别入画、形态别变、别配乐、别长某元素。模型最容易在这些地方自由发挥。

## ⑥ 反"AI 塑料感"锚（film not render）

标杆作品的电影感写实家族几乎每条都挂"是胶片不是渲染"。**真人写实剧（如巴别塔）务必在 STYLE LOCK 里保留这组锚**：真实胶片颗粒 / 实景光 / 照片级电影定格 / 透过镜头的真实物理场景 / 不是 3D 渲染、不是 CG。古装、航拍等非写实家族可不挂——一切以 `bible.style` 的定位为准。

# Drama Shot Prompt（镜头提示词）

把 `drama-storyboard` 的分组分镜头表，转成**每组一段、可直接喂视频生成模型（Seedance 2.0）**的提示词。保留分镜的分组/镜号/时长不变，把"画面"翻成可执行的**导演级渲染提示词**——密度和手法对标公开标杆《万物生》。

**动手前先读两份参考**（按这个顺序）：
1. **[`references/万物生-prompt-craft.md`](references/万物生-prompt-craft.md)**（手艺范本）——7 个核心技法 + 3 档完整真例 + 密度校准。**这是提示词质量的标尺。**
2. [`references/sd2-render-spec.md`](references/sd2-render-spec.md)（分层骨架、STYLE LOCK 写法、增强层细则）——结构规范。

流水线契约见 `docs/流水线设计.md`。

**这一步 = 渲染规格层**：③ 定了"演什么 / 怎么调度"（编辑层），④ 定"模型该怎么渲染"。你的活是把 ③ 的编辑决策，补上 STYLE LOCK、**逐镜的画面空间分层与构图**、物理相机参数、台词三件套、声音底层、以及（重点镜的）三段编舞与念白指导。别回头改 ③ 的镜头语言。

**④ 不写 `@[]` 图像锚**——资产锚定是 ⑤ 的工作。④ 只用 bible 里的 `display_name` 指代主体，把"谁在画面里、关键外观、什么状态"用文字写清楚。

## 输入
- `docs/scripts/<剧名>/<集>/分镜/分镜头.md` + `分镜头.json`（③产出；`分镜头.json` 每组带 `分量`）。也接受粘贴的分镜头内容、或含多集分镜头的目录（**批量**：每集各出一份）。
- **读 `docs/scripts/<剧名>/bible/bible.json`**（结构见 `docs/asset-schema.md`）：取 `style_lock`（②已写好的全剧渲染常量，**原样**用）；从 `assets[]` 取人物/场景/道具的 `display_name`、`intent` 中的外观要点（按 `display_name` + 本集适用 look：`intent.planned_episodes` 含本集的那条），用于写「本组主体」描述。
- 兜底（别因上游不完美就罢工）：
  - 无 bible → 提示先跑 `drama-bible`；仍要出活就降级：STYLE LOCK 用通用写实锚、主体用中文名+从剧本/分镜推断的外观。
  - 给整本/未分镜 → 提示先跑 ③；给未分组扁平表 → 先按 15s 切组再转。
  - 某组缺 `分量` → 按内容当「常规」走**标准档**；缺时长/镜数 → 推断最合理可执行值。

## 定档：所有组默认标准档
**所有组一律使用标准档**，无论③标的 `分量` 是什么。手艺层参照 [万物生范本](references/万物生-prompt-craft.md) 的三、档位密度校准。

| ④档位 | 手艺层 |
|---|---|
| **标准**（唯一档） | STYLE LOCK + 主体描述 + **每镜画面构图(含空间层次：前景/焦点/背景×谁清晰谁虚化)** + 台词三件套(至少原话+怎么念) + 声音底层 + 物理相机(景别+焦段+机位高度+运动) |

**标准档的底线**：**每镜必须有一条画面构图描述，包含空间层次**——如果你写的标准档是"每镜一句话"，太薄了，回去看范本再加。

## STYLE LOCK（顶部一次，全集复用）
读 `bible.style_lock`（②已写好的全剧渲染常量），**原样**放 `镜头提示词.md` 顶部，全集每组共用同一段——别自行扩写或逐组改写。同时写进 JSON 的 `style_lock` 字段。（若 bible 没有 `style_lock`、只有短 `style`，才退而按 [sd2-render-spec.md](references/sd2-render-spec.md) 自渲一段。）

## 主体描述（每组，用名字指代）
本组出现的每个人物/场景/关键道具，在组头写一段「本组主体」。做法：拿 ③ 的名字去 `bible.assets[]` 找对应资产（`display_name` 匹配 + 选 `intent.planned_episodes` 含本集的 look），取其外观要点，写成：
```
本组主体与关键道具：
- 领航员K——炭灰长袍领航装/五官参照 bible/出现镜3-4/状态：静坐高台、侧对舷窗
- 诺亚方舟内部大厅·幽暗——舷窗冷光/幽暗/本组全程
```
**不写 `@[]` 锚定符**——图像锚定（把名字 pin 到参考图）是 ⑤ 的工作。④ 只负责用**文字**把主体的关键外观和本组状态写清楚，密度参照万物生范本的满配范例中"本组主体与关键道具"段。

## 输出
```
docs/scripts/<剧名>/<集>/提示词/
├── 镜头提示词.md      人读（顶部 STYLE LOCK + 每组一段）
└── 镜头提示词.json    结构化镜像（供 ⑤4b / ⑥SD2 解析）
```
两份内容必须一致。`镜头提示词.json` schema：
```json
{
  "episode": "第N集_集名",
  "style_lock": "……STYLE LOCK 全文（全集一致）……",
  "groups": [
    { "group": "第一组", "组名": "废土降临", "分量": "常规", "档位": "标准",
      "镜头数": 4, "总时长_秒": 15,
      "主体描述": [
        { "display_name": "领航员K", "外观要点": "炭灰长袍领航装", "出现": "镜3-4", "状态": "静坐高台、侧对舷窗" },
        { "display_name": "诺亚方舟内部大厅·幽暗", "外观要点": "舷窗冷光/幽暗", "出现": "全程" }
      ],
      "场景": "诺亚方舟内部大厅·幽暗",
      "shots": [
        { "镜号": 3, "时长_秒": 4, "景别": "大全景", "运镜": "极缓推", "视频提示词": "……" }
      ] }
  ]
}
```
`主体描述` 的 `display_name` 必须能对回 bible（供 ⑤ 按 display_name 找 ref_token 锚定）；`shots` 的 `镜号/时长` 与分镜头一致，和 = `总时长_秒`。满配档的三段编舞/念白指导直接写在该镜 `视频提示词` 文本里（无需额外字段）。

## 格式（每组一段，按档位铺层）
顶部先放一次 STYLE LOCK，然后每组按其档位写。每组通用骨架：
```markdown
## 第N组｜组名　[档位：标准]
镜头数：4个｜总时长：15s｜分量：常规
本组主体与关键道具：
- 领航员K——炭灰长袍领航装/五官参照 bible/出现镜3-4/状态：静坐高台、侧对舷窗
- 诺亚方舟内部大厅·幽暗——舷窗冷光/幽暗/本组全程
场景：诺亚方舟内部大厅·幽暗
视频提示词：
镜头3（4s，大全景，极缓推，焦段24mm广角）：画面前景是幽暗舱壁结构的纵深框架+中景焦点是K静坐右上高台侧对舷窗、机器僧左下盘坐+背景舷窗外死寂地球……
镜头4（4s，中近景，固定，焦段85mm长焦+浅景深）：K侧脸前景清晰+背景舷窗外文明残骸严重虚化散景……
```
- `视频提示词` 下**每镜独占一行**（满配档可在该镜下分 开篇/中段/末段 多行编舞）。绝不把多镜并成一段。
- **标准档每镜至少写**：景别+焦段+运镜 → 画面空间分层（前景/焦点/背景）→ 主体动作+表情 → 台词（原话+怎么念）→ 声音。密度对标[万物生范本](references/万物生-prompt-craft.md)的标准范例（~1800字/组）。
- **精简档每镜**：一条画面+动作+声音，不用空间分层。密度对标范本的精简范例（~1100字/组）。
- 把分镜头里该镜的机位/角度（俯/仰/过肩/侧）一并带进景别·运镜。
- ③ 在运镜里挂的 Master Shots 技法名（如 Tilt Reveal、Rest Point）可作轻提示保留在景别·运镜的括注里，但必须有**具体机位/运镜措辞**兜底。

## 语言纪律
- **导演语**：中文
- **镜头术语**：留惯用英文（HARD CUT / whip pan / shallow depth of field / anamorphic / pan / zoom in / close-up / deadpan / static / handheld 等不翻译）
- **台词/旁白(VO)**：**跟剧本原语言走，一字不改**——剧本是英文台词就写英文，中文就写中文。不为配合中文导演语去翻译台词
- **STYLE LOCK**：从 bible 原样取，不改语言

## 规则（保真 + 不改结构 + 时长锁定）
- 默认中文导演语。**只输出最终提示词文本 + 主体描述**，不要分析/解释/自检过程、不要解释性废话。
- **照搬不改结构**：分镜头几组就几组，组顺序/组名/镜号/各镜时长一律照搬；不合并/拆分/重排/改名分组——唯一例外是修复时长锁定。
- **③ 是唯一源**：以本集 `分镜头.{md,json}` 为结构与内容的唯一来源。若旧 `镜头提示词` 已存在，**整文件覆盖重写、不继承旧措辞/旧时长**——上游 ③ 更新后 ④ 必须随之刷新。
- **时长锁定 + 修复**：每组总时长 = 各镜时长之和；非最终组正好 15s、最终组 ≤15s。上游凑不齐就最小化修复（移边界镜/拆提示词行/±0.5s）。写精确值（`15s`/`9.5s`），不写"约15s"。
- **保真**：完整保留剧情推进、人物关系、对白/旁白(VO)、音效、关键道具、服装、③给的主体细节；保持空间连续性（前中后景、朝向、视线、动作方向、**机位轴线别跳轴**）。音效用中文 `音效：…`。
- **不新增**剧情/人物/道具/设定；可压缩重复措辞，但不丢重要情节和台词。
- **缺信息也要出活**：某组关键人物关系/空间/对白缺失，仍输出最佳可执行版本，并在该组**末尾补一句**点明缺了什么——不罢工、不瞎编。

## 自检（写文件前）
- 顶部有 STYLE LOCK，且 JSON `style_lock` 与之一致；STYLE LOCK 在所有组之间是同一段（没逐组改写）。
- **每组档位均为标准**。
- **每组有主体描述**：本组出现的人物/场景/关键道具各有一条（display_name + 外观要点 + 状态），名字能对回 bible。
- **标准档+满配档的每镜都有画面构图**（含空间层次：前景/焦点/背景，谁清晰谁虚化）——如果是"每镜一句话"，**太薄了，不合格**。对照[万物生范本](references/万物生-prompt-craft.md)的标准范例密度。
- 组数/组名/镜号/各镜时长与分镜头一致（除非修复时长锁定）；非最终组正好 15s、最终组 ≤15s，写精确值；组与组之间空一行。
- 每镜独占一行（满配档三段编舞除外）；覆盖全部镜头序列；对白/VO/音效/道具/服装/主体细节都在；空间连续性没乱。
- 不硬塞三段编舞/集中负向约束段（但散在描述中的小约束如"禁止X入画"是好的）。
- **台词/VO 用剧本原语言**，导演语用中文，术语留英文。
- 无 Markdown 表格、无解释性废话；源里缺的关键信息已在对应组末点明。

## 交付报告
报告：生成了哪些集、各几组、总时长、**每组的档位（满配/标准/精简）分布**、主体描述的 display_name 清单（供 ⑤ 预判要出哪些素材）；任何 bible 里查不到、需回补的 display_name；批量任务里被跳过或受源限制的集。

# Drama Storyboard（分镜头）

像专业影视分镜师 + 导演，把单集剧本拆成**分组的、可拍可审阅的分镜头表**。忠于剧本：用景别、反应镜头、动作分解、转场让叙事更清楚，不新增情节、不改人物关系或结局。产物 `分镜头.md` 供第④步 `drama-shot-prompt` 转成 SD2 视频提示词。流水线契约见 `docs/流水线设计.md`。

## 职责边界：只做"与渲染模型无关的编辑决策"

你是导演 + 剪辑，不是渲染工程师。把每个镜头的**戏与镜头语言**定死，但**不写任何针对具体生成模型（SD2）的渲染规格**——那是第④步 `drama-shot-prompt` 的活。这条线让 ③④ 互不侵蚀、各自可预测，也让分镜头换任何渲染模型、甚至真人实拍都成立。

- **③ 负责（编辑层）**：切点与分组、镜序、节奏(4–15s)；景别 + 运镜 + 焦点意图（浅景深/虚化/对焦在谁）+ **Master Shots 技法**（镜头语言的*意图*）；站位 / 轴线 / 视线 / 动作方向 / 连续性；每镜服务什么戏、情绪转折、台词与**怎么演**（表演意图）；用 bible 名指认人物 / 场景 / 关键道具（供 ④ 锚定）。
- **③ 不负责（渲染规格层，留给 ④）**：STYLE LOCK 风格块与"是胶片不是渲染"质感锚；`@[资产]` 图像锚、HEX 色卡；焦段 mm / 镜头投影 / 光圈与景深的**技术实现**（"浅景深"这种焦点*意图*属 ③，f 值 / mm 这种*实现参数*才属 ④）；分段时间线（开篇/中段/末段）、念白语气、口型同步；声音底层指令、负向约束、转场技术标记。

一句话：**③ 决定"演什么、怎么调度、为什么"；④ 决定"模型该怎么渲染"。** 别在分镜头里写 mm / HEX / STYLE LOCK——写了反而把下游绑死。

## 输入
- 单集剧本：`docs/scripts/<剧名>/第N集_*/…txt`（或用户指定集 / 粘贴文本）
- `docs/scripts/<剧名>/bible/bible.json`——**先读**（结构见 `docs/asset-schema.md`）：从 `assets[]` 取人物/场景/道具的 `display_name`（按 `id` 去重）来写画面，保证全剧一致（④/⑤ 靠这些名字映射回 `id`）；并留意每个对象**本集适用的 look**（`intent.planned_episodes` 含本集的那条），写场景时带上对应 look 状态（如"诺亚方舟内部大厅·幽暗"）。无 bible 提示先跑 `drama-bible`
- 给整本未拆 → 提示先跑 `drama-script-split`

## 输出
```
docs/scripts/<剧名>/<第N集_集名>/分镜/
├── 分镜头.md      人读的分组分镜头表
└── 分镜头.json    同内容的简单结构化镜像（供下游 ④/⑤ 解析）
```
两份内容必须一致（MD 给人看、JSON 给机器解析）。`分镜头.json` 只是**内容镜像**，不含资产/id 绑定（那是 ⑤4b 的事）。简单 schema：
```json
{
  "episode": "第N集_集名",
  "groups": [
    { "group": "第一组", "组名": "废土降临", "时长_秒": 15, "分量": "常规",
      "shots": [
        { "镜号": 1, "时长_秒": 4, "景别运镜": "[大远景，固定]（Tilt Reveal）",
          "画面": "...", "光影氛围": "...", "对白音效": "..." }
      ] }
  ]
}
```
组里 `shots` 各镜时长之和 = 组 `时长_秒`；非最终组 = 15。每组必带 `分量`（`重点` / `常规` / `过场`，默认 `常规`，含义见下「给每组标分量」）。

## 设计前先查镜头语言
分镜头质量取决于镜头语言是否有目的。设计每个 beat 前，读 `references/master-shots.md`，按戏剧情境（冲突/对话/揭示/情绪/边走边聊/出场退场/动作）挑合适技法来定景别·机位·运镜，并把技法名标进 `景别/运镜` 列。避免通篇泛泛的"中景，固定"。

## 分组规则（时长锁定）
- **一组 = 后续一条 SD2 视频片段**。按叙事节拍切组：一个连续的小节奏/一个动作单元/一段对话回合为一组。
- **时长锁定**：每个**非最终组的总时长必须正好 15s**；只有**最终组**可短于 15s（4–15s），任何组都不得超过 15s。组时长 = 组内各镜时长之和。
- 凑齐 15s 的手段（**不新增剧情**）：相邻组间移动边界镜头、拆分或合并已有节拍、以 0.5s 为单位微调镜头时长、或增加忠于剧情的反应/插入/转场镜头。
- 反过来**装不下**时（该组要念的台词时长 + 必须保留的剧本节拍 > 15s）：优先压缩纯环境/空镜镜的时长；其次（尤其旁白 VO）让台词自然跨到**下一组首镜**延续；**别**为塞满而注水，也别把台词逼得念太赶——念白完整比凑满 15s 重要。
- 组标题写实际时长：非最终组 `## 第一组（15s）｜[组名]`；较短的最终组写准确值，如 `## 第五组（9.5s）｜[组名]`。组名是这组的一句话概括。
- **组数 ≈ 总时长 ÷ 15s**（30s≈2组、90s≈6组、300s≈20组）。普通剧集不要压成只有 1 组（除非源只有一个极短节拍且用户接受）。

## 给每组标"分量"（让 ④ 决定渲染档位）

不同片段值得的渲染精细度不同：一段多动作转折的高潮戏，和一个交代环境的过场空镜，不该花同样力气。你最懂剧情轻重，所以**由你给每组标一个分量**，④ 据此决定铺多少渲染层。分量是**编辑判断（这段戏多重）**，不是渲染参数——你只回答"这段戏分量多重"，怎么渲染仍是 ④ 的事。

- **重点**：内部有多个动作节拍 / 情绪转折的高潮或关键戏（打斗、变身、当众揭穿、连锁反应）。→ ④ 上「满配档」（分段时间线 + 色卡 + 念白指导）。
- **常规**（默认）：一般对话、单一动作、过肩反打这类标准片段。→ ④ 出「标准档」（内核五层）。
- **过场**：纯环境 / 插入 / 空镜、几乎无表演，**且无关键台词/旁白(VO)**的片段。→ ④ 出「精简档」。

**戏重要但画面/表演简单时怎么判**（点题旁白镜、伏笔插入镜常遇到）：分量决定的是"④ 该为这段戏花多少渲染力气"，而花力气是为了"有需要编舞/精雕的东西"。所以——**承载关键台词/旁白(VO) 的镜组至少是「常规」**（它需要 ④ 的念白指导，不能掉到精简档把台词糊弄过去）；只有连要紧台词都没有、纯交代环境氛围的，才标「过场」。一句话：**有要紧的话要说 → 至少常规；只是交代背景 → 过场。**

**标注方式**：`分镜头.json` 里每组写 `"分量"` 字段；MD 里只给**非默认**的在组标题末尾加一个角标——如 `## 第七组（15s）｜兽笼夺剑　【重点】`、`## 第十二组（9.5s）｜空镜过场　【过场】`；「常规」不标，保持表头干净。**克制用「重点」**：通常一集只有几处真正的高潮值得满配，全标=没标。

## 创作规则
- **忠于剧本**：不加情节、不改关系/结局；只用反应/动作分解/环境/转场让原故事更清楚。
- **台词/旁白(VO)保留剧本原语言，一字不改**：剧本是英文台词就写英文，中文就写中文。不翻译台词——后续 ④ 和模型都需要原语言。
- 镜号从 1 连续递增（整数，跨组不重置）；时长用 0.5s 增量，单镜 0.5–10s（短反应 0.5–1.5s，对白/动作多为 1.5–4s）。
- **台词必须念得完**：镜头时长要能覆盖该镜对白/旁白自然念完所需的时间。台词长时三选一——① 不伤剧情情绪地精简台词；② 把该镜时长拉长到够念完（单镜上限 10s）；③ 仍放不下，就让台词跨**本组内**多个镜头延续（配反应/插入/角度变化镜头），意思不变。**绝不让镜头切走时台词还没说完。**
- 画面里**用 bible 的人物/场景/关键道具名**（如"领航员K""机器僧""诺亚方舟内部大厅""皇帝邀请函"），别另起名——后续 ④ 要靠这些名字逐个锚定参考图（`@[资产]`），名字不一致下游就锚不上。出现的、对剧情重要的道具也点名（哪怕 bible 暂未收录，用稳定的中文名即可）。
- 写可拍的表演细节：微表情、视线、肢体、呼吸、迟疑、姿态。保留重要台词与音效（音效写中文 `音效：…`）。
- 保持场景内连续性：站位、道具、时间、光线、视线、动作方向。
- `景别/运镜` 用具体词：大远景/全景/中景/近景/特写；推/拉/摇/移/跟拍/俯/仰/固定/手持；并尽量挂一个 Master Shots 技法名。

## 写文件前自检（硬性，全部通过再写文件）
- **时长锁定**：每个非最终组总时长**正好 15s**；只有最终组可短于 15s；任何组 ≤15s。组内各镜时长之和 = 组标题时长。凑不齐的组先用上面的"凑齐手段"修好。
- 单镜时长 0.5s 增量、**≤10s**；短节拍 0.5–1.5s，多数对白/动作 1.5–4s。
- **台词都念得完**：每个有较长台词/旁白的镜头，其时长（或跨本组多镜延续的总时长）足以自然念完。
- 镜号在整集**连续整数**、不在组内重置；每组都是六列表格、列齐全；不是单个未分组的扁平表。
- 组数 ≈ 总时长 ÷ 15s；普通剧集没被压成只有 1 组。
- **不引入新剧情事件、不改人物关系或结局**；画面覆盖关键剧情节点、情绪转折、重要对白和可拍的表演细节。
- **台词/VO 保留了剧本原语言**，没被翻译成其他语言。
- 镜头语言有目的（多数镜头带 Master Shots 技法），不是通篇"中景固定"。
- 人物/场景/关键道具名与 bible 一致。
- **每组都定了分量**（`分镜头.json` 必带 `分量` 字段；MD 里「重点」「过场」加角标、「常规」不标）。「重点」克制使用，通常一集只有几处真正的高潮；分量判断对得上剧情轻重。
- **没越界写渲染规格**：分镜头里不含焦段 mm、HEX 色值、STYLE LOCK、`@[资产]`、分段时间线、念白语气指导——这些都属于 ④，写了反而绑死下游。
- 输出文件里**不含**解释、总时长计算、修订说明、草稿表格或自检过程。

## 交付报告
报告：生成了哪些集的 `分镜头.md`、各几组、总时长、其中标「重点」/「过场」的组各是哪些（让用户一眼看到 ④ 会在哪几处上满配/精简）；任何与 bible 不一致需回补的项；批量任务里被跳过或受源内容限制的剧集。
